Synology Microsoft SQL Backup & Restore

Резервное копирование баз Microsoft SQL Server на NAS и восстановление из этих копий. Автор: Ермаков Алексей Сергеевич, ИП Ермаков А.С.

О программе

Задание подключается к Microsoft SQL Server, выполняет BACKUP DATABASE в папку на этом сервере, забирает файл по SMB на NAS и хранит его в виде архива .bak.gz. Расписание выполняет сам пакет, Планировщик DSM не нужен.

Перед началом

  • На Microsoft SQL Server создайте папку для копий, например D:\SQLBackups. Учётная запись службы SQL Server должна иметь право записи в эту папку.
  • Откройте эту папку как общую SMB-папку. NAS забирает и отдаёт файл только по SMB: SQL Server не принимает путь вида \\NAS\share в команде BACKUP.
  • Для входа в SQL используйте проверку подлинности SQL Server, не только Windows.
  • Пакет слушает порт 8088 на NAS. Если окно пустое, разрешите этот порт в брандмауэре DSM.

Создание задания

Нажмите +. Мастер состоит из пяти шагов, как у Hyper Backup.

  1. Подключение. Имя задания, адрес Microsoft SQL Server, порт (обычно 1433), пользователь и пароль. Кнопка «Проверить подключение» читает список баз.
  2. Базы и хранение. Отметьте базы. Укажите папку на SQL Server и SMB-шару этой же папки (\\сервер\share), пользователя и пароль SMB. Папку на NAS выберите в дереве тома; новую папку можно создать здесь же.
  3. Расписание. Дни недели, время начала, повтор в течение дня и время окончания. Расписание можно выключить.
  4. Ротация. По числу копий или Smart Recycle: почасовые за сутки, ежедневные за месяц, еженедельные старше месяца, не больше заданного числа версий.
  5. Запуск. Отметьте, нужно ли выполнить копирование сразу после сохранения.

Готовое задание меняется кнопкой Изменить. Пароли можно не вводить повторно. Удаление задания не удаляет уже лежащие на NAS архивы.

Запуск и ход

Кнопка Резервировать сейчас запускает выбранное задание. Шкала показывает подготовку, процент BACKUP, копирование на NAS и архивацию. После успешного копирования временный .bak на SQL Server удаляется. На NAS остаётся .bak.gz.

Журнал

У каждого задания свой журнал. Внизу карточки видны только его строки. Общий журнал всех заданий не смешивается.

Восстановление

  1. Выберите задание и нажмите кнопку восстановления.
  2. Выберите базу этого задания и дату копии. В списке даты, а не имена файлов.
  3. Сервер, порт, пользователь, пароль, папка и SMB подставляются из задания. Любое поле можно изменить, в том числе указать другой Microsoft SQL Server.
  4. Имя базы на сервере назначения тоже можно изменить.

Архив распаковывается рядом с копией на томе, передаётся по SMB и восстанавливается командой RESTORE DATABASE. Ход виден на той же шкале. Временные файлы после работы удаляются.

Служба SQL Server на машине назначения должна иметь право создавать файлы базы в указанной папке.

Лицензия

Серийный номер NAS пакет читает сам из DSM. Вводить его не нужно.

Без активации можно создать только одно задание. Уже созданные задания продолжают выполняться по расписанию. Второе задание появится после активации.

Ключ выпускается в компоненте «Лицензии приложений» на сайте ип-ермаков.рф. У ключа должно быть приложение с кодовым именем mssqlbackup. Кнопка Лицензия в окне пакета отправляет ключ и серийный номер DSM на сайт.

Пакет спрашивает сайт не чаще одного раза в час. Если интернета нет или сайт не открывается, уже активированная лицензия не отключается. Лицензия снимается только когда сайт явно ответил, что ключ отозван, просрочен, не найден или привязан к другому серийному номеру.
